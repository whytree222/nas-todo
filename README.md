# 私有待办 · NAS Todo

给绿联 DX4600 使用的个人待办项目：安卓和 Windows 原生客户端共用 Flutter 源码，Docker 同步服务和 SQLite 主数据库放在自己的 NAS 上。

**[v0.9.1 测试版已发布](https://github.com/whytree222/nas-todo/releases/tag/v0.9.1)**，新建和编辑待办可直接选择已有分组，也可手输新名称。两端静态分析、安卓102项/Windows103项客户端测试、24项后端测试及原生编译通过；安卓8项原生小组件检查通过。见 [安装说明](docs/RELEASE-v0.9.1.md) 和 [验证记录](docs/VALIDATION.md)。本次无需修改NAS服务。

## 可以做什么

- 新建、编辑、完成和删除待办；清单分类、搜索、今天与已完成筛选。新建/编辑时可用清单右侧下拉按钮选择已有分组，或输入新名称。
- 截止日期、优先级和排序。
- 应用主题：黑、白、绿、蓝；小组件可跟随应用，也可独立选色。颜色选择在每台设备本机保存。
- 今日鼓励：完成当天最后一项已安排待办后显示笑脸星星、彩纸与鼓励句。每台设备每天最多一次；离线保存成功也可触发，支持减少动态效果。无待办、同步、删除、改期不会新触发。
- 成就：每个有待办的周段完成率 ≥80% 得星；全年十二个格子记录月底结果，所有有待办周段达标则绿，否则红，无待办则灰。跨年自动切换，旧年保留。NAS 月底先归档再清理该月有日期、有分类的全部待办，保留收件箱、未分类和无日期待办。
- 月历与每日待办：七列适配窗口宽度，按月份显示四至六周，每周按待办数量自动增高，直接展开当天全部待办；完成后保留原位置并划线。Windows 可拖动空白处或使用滚动条，手机上下滑动；日期格中的“详情”查看完整名称和编辑入口。未安排卡片可拖到日期。
- 安卓桌面小组件：今日清单、全部待办、未来七天、简洁今日和卡片轮播，可在桌面滑动浏览全部任务；每条显示蓝色普通、琥珀色较高、红色紧急徽标，黑白绿蓝主题都适配。浏览不打开应用，明确勾选时打开应用保存。
- Windows 独立毛玻璃桌面组件：运行 desktop-widget.cmd，关闭主界面后仍可使用；可选择黑、白、绿、蓝颜色，保留圆角卡片、圆形勾选图标和“…”菜单。拖动、调整大小、贴四边收起和悬停展开，记住位置、置顶及贴边选项。
- 先保存本机，断网时照常编辑；联网后上传到 NAS，并拉取其他设备的修改。
- 手动同步、应用打开期间定时同步、回到前台时同步；显示待上传数量和同步结果。
- 两台设备同时修改同一条待办时显示冲突，由你选择本机或 NAS 版本。

这是一位使用者、一个共享访问令牌的第一版。暂未实现附件、多人权限和到期通知。手机应用退出后不保证后台同步；再次打开会尝试同步。

## 数据在哪里

```text
安卓客户端 ─ 本机离线副本 ─┐
                          ├─ 私有网络 / HTTPS ─ DX4600 Docker 服务 ─ SQLite 主库
Windows 客户端 ─ 本机副本 ─┘                              └─ NAS 备份
```

NAS 保存完成同步后的主库和备份。离线新增的内容在同步成功前只存在创建它的设备上；两台设备都必须保留本地副本才能离线使用。访问令牌放在客户端系统安全存储中，待办的本地副本使用应用数据目录保存，并没有单独进行内容加密。同步服务不使用待办 SaaS，也没有内置遥测。

NAS、安卓和 Windows 已经加入同一个 ZeroTier 网络，直接沿用现有网络。客户端填写 NAS 的 **ZeroTier Managed IP**，例如 `http://NAS的ZeroTierIP:8787`，待办主库仍保存在 NAS；Managed IP 可在现有网络的设备列表查看。[ZeroTier 官方说明](https://docs.zerotier.com/quickstart/)

## 从这里开始

1. 按 [DX4600 部署说明](docs/DEPLOY-DX4600.md) 把同步服务装到 NAS，生成自己的访问令牌。
2. 从 [Release](https://github.com/whytree222/nas-todo/releases/tag/v0.9.1) 下载安卓 APK 与 Windows完整ZIP。NAS若尚未升级成就服务，仍需按 [v0.7.0 升级说明](docs/UPGRADE-v0.7.0.md) 更新；已升级者不用为安卓小组件重复部署。
3. 在两台设备的“连接设置”中填写同一 NAS 地址和同一访问令牌。
4. 用 NAS 的 ZeroTier IP 验证 `/health` 和同步，再让手机切到移动网络测试；最后验证断网修改和双端冲突。

## 日常使用注意

先等应用显示同步成功，再卸载、清除应用数据或换设备；未上传修改可能随本地数据一起丢失。连接设置中的令牌相当于主库访问权限，妥善保存，不要把 `.env`、备份或客户端数据目录提交到公开仓库。

服务端通过版本号识别修改，不依赖手机与电脑时钟一致。已确认同步的数据定期用 SQLite 在线备份命令保存，具体步骤见部署说明。
