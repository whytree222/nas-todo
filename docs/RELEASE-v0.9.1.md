# v0.9.1 已有分组选择测试版

新建或编辑待办时，可以直接选择已有分组，不必重复输入名称。

- 点击「清单」输入框右侧的下拉箭头，选择已有分组。当前名称不会限制显示的选项，不用先清空「收件箱」。
- 选项包括本机已有待办使用的清单（包含已完成待办），以及收件箱和当前编辑/选定的清单；重复名称合并。
- 仍可直接输入新的清单名称，保存待办后即可在后续新建时选择。
- 选择清单会保留正在填写的标题、备注、日期和优先级；多个清单可以滚动选择。手机与 Windows 同时支持。

安卓下载 `nas-todo-android-v0.9.1-test.apk`；Windows 下载并解压完整的 `nas-todo-windows-v0.9.1-x64.zip`，保留 DLL 与 data 目录。本次无需修改 NAS 服务。

APK 仍为测试签名，更新前先同步并保留未同步数据，不要直接卸载含未同步待办的旧版本。更新后打开应用一次即可使用；原有小组件与鼓励功能继续保留。
