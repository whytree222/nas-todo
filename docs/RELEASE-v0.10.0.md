# v0.10.0 个人工作台测试版

参考使用者提供的滴答清单静态功能分析，使用独立实现的布局、图标和代码组织个人工作台。Windows 有导航栏、智能清单侧栏、任务区和可收起详情；安卓有底部导航与清单抽屉。支持黑、白、绿、蓝主题。

- 智能清单：全部、收件箱、今天、未来七天、重要、逾期、未安排、已完成；支持清单、标签、搜索及优先级筛选。快捷添加会带入当前清单、标签或今天日期，Windows 支持 Ctrl+N、Ctrl+F、Esc。
- 子任务：最多五层，可展开、收起、编辑和独立完成。详情里查看子任务、添加下一步。删除父待办时子任务保留为顶层；父任务不会自动勾选或删除全部子任务。
- 标签：新建或编辑时添加、选择已有标签；侧栏按标签查看任务，也能搜索标签。
- 重复待办：按天、周或月重复，可设置间隔、每周执行日和每月日期。完成并同步后 NAS 根据这一次的安排日期生成下一次，保留标签、清单、备注和优先级。月末不足指定日期时使用当月最后一天。离线先保存完成状态，下次同步后生成下一次。撤销后再次完成不会重复生成；已生成的下一次请直接编辑下一条。子任务分别设置自己的重复规则。
- 看板与四象限：看板按普通、较高、紧急优先级分列；拖动或菜单可调整。四象限以较高或紧急优先级判断重要，以今天及之前日期判断紧急。移出紧急象限会清除已到期日期，重复任务改到明天，未来日期保留。
- 日历：月、周、日、议程切换，默认完整月历；当天全部任务可滚动查看，完成后保留划线。空日期可新建，无日期任务可拖到目标日。
- 习惯：勾选或次数目标，每天或每周指定日执行；当天打卡、撤销、近七天记录、月热力图及历史补记。周达标率按截至今天的计划日计算。习惯及打卡记录独立存入 NAS，不受待办月底清理影响。

保留离线编辑、NAS 同步冲突选择、原成就和今日鼓励、安卓五种滑动组件以及 Windows 独立毛玻璃组件。按使用者最新要求，不提供番茄钟。原分析没有实际运行截图，多栏尺寸、配色、图标及四象限规则均为本应用设计。

## NAS 升级

**新个人功能需要升级 NAS 服务。** 按 [v0.10.0 升级说明](UPGRADE-v0.10.0.md) 在原 Docker 项目更新服务代码，保留原令牌、data 和数据库。升级会在同一个 SQLite 数据库增加独立的个人记录表，不重建原待办表。旧版客户端仍能读写原待办，无法修改或展示新的个人信息。新客户端连接旧 NAS 时，基本待办照常同步，个人信息留在本机等待上传，并显示升级提示。

升级前先让两端同步并备份。不要卸载或清除有待上传内容的旧应用。APK 仍是测试签名，跨构建覆盖安装取决于签名是否相同。Windows 解压完整 ZIP，保留 DLL 和 data，运行 nas_todo.exe；独立组件继续运行 desktop-widget.cmd。

月底成就规则保持不变：先归档，再清理该月有日期、有分类的全部待办（含未完成），保留无日期、收件箱和未分类待办；保留下来的子任务会提升为顶层。历史成就、标签和重复信息包含在数据库备份中。
