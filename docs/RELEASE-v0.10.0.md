# v0.10.0 工作台测试版

本版参考使用者提供的滴答清单 8.1.2.0 静态分析，重新组织私有待办的界面和交互。Windows 使用导航栏、清单侧栏、任务列表和可收起的详情栏；安卓使用底部导航和清单抽屉。保留黑、白、绿、蓝主题、NAS 同步、离线编辑、成就、完成鼓励和独立桌面组件。

- 智能清单：全部、收件箱、今天、未来七天、重要、逾期、未安排和已完成；保留分组筛选与搜索。
- 快捷添加直接保存离线待办，带入当前分组或日期；Windows 支持 Ctrl+N 新建、Ctrl+F 搜索和 Esc。
- 列表、按优先级看板、四象限切换，支持拖动和菜单调整任务位置。四象限规则：较高/紧急优先级为“重要”，今天及之前的日期为“紧急”。移动会明确修改优先级或日期；移出紧急象限会清除已到期日期，未来日期保留。
- 日历增加周、日和议程视图，仍默认完整月历；每天全部待办可查看，完成后保留划线。空日期可直接新建，未安排任务可拖入日期。
- 新建及编辑的分组继续支持选择已有清单或手工输入新名称。

本轮没有添加标签、子任务、重复任务、习惯或番茄钟。它们需要独立数据模型与后续 NAS 协议升级；界面没有放入无效入口。报告没有实际运行截图，多栏尺寸、配色和图标是本应用的设计，未使用滴答清单的源码、品牌标识或素材。

参考边界：使用者提供的功能、资源和代码核验报告确认了智能清单、任务详情、看板、四象限和多种日历视图的结构。当前四象限的判断规则、看板按优先级分列及日期分组日历，均按私有待办现有数据设计；不声明与滴答清单内部规则或运行画面一致。

已有 v0.7.0 及之后的 NAS 成就服务无需重新部署，地址、令牌和数据继续使用。安装前先同步并保存备份；APK 仍为测试签名，跨构建覆盖安装取决于签名是否相同，不要删除尚未同步的旧应用数据。Windows 请解压完整 ZIP，保留 DLL 与 data 目录，运行 nas_todo.exe；独立组件继续运行 desktop-widget.cmd。
