# v0.11.0 界面改版与习惯成就测试版

参考使用者提供的前端静态分析，保留现有功能，重新整理导航、编辑器和信息层级。沿用 Flutter、独立图标和本应用配色，不添加时间线或番茄钟。

- 手机底栏：待办、日历、习惯、成就、设置。今天和已完成保留在待办的智能清单中。Windows 在日历、习惯等页面收起无关清单侧栏。
- 待办列表强化标题、日期和标签层级，保留子任务、重复规则、清单选择、筛选与看板。四象限默认隐藏，在“设置 → 功能显示”开启；关闭只隐藏入口。
- 手机任务编辑使用底部面板，可展开全屏；Windows 大窗口在右侧编辑。离开有未保存更改的编辑器时提示保留输入，继续保留同步期间的新版本冲突确认。
- 手机快速添加移至底部，输入时可选择清单、日期、优先级和已有标签。显示偏好在当前设备保存，不同步到其他设备。
- 习惯保留打卡、次数、计划日和补记，月热力图收进历史区域。黑白绿蓝主题、成就热力图、今日鼓励及两端桌面组件保留。

## 习惯计入成就

**每周待办完成率和习惯达标率分别达到80%才得星。** 某一类没有计划时不参与判定；两类都没有计划的周段不评分。

习惯达标率＝习惯达标天数÷习惯计划天数。每个习惯的每个计划日算1天，次数目标当天达到才算达标；例如每天喝水8次，完成8次记1天，不是8项。休息日不计入，实时进度不提前计算未来习惯日。

习惯计划与目标按修改日期保存历史，修改或删除从当天生效，以前日期保留原计划。新规则从NAS升级当天开始，已有习惯不会被补算升级前的义务；新建习惯的离线计划在同步后保留。已结算成就不回改。月底仍只归档清理已确认范围的待办，习惯和打卡记录保留。

## 升级与安装

**本版需要升级NAS结算服务。** 先让两端同步，停止原项目并备份整份data目录，在原项目替换本聊天提供的私有compose.yaml后重新部署。保留原令牌、端口和挂载，无需init容器。详见 [升级说明](https://github.com/whytree222/nas-todo/blob/main/docs/UPGRADE-v0.11.0.md)。私有配置包含密钥，不上传GitHub；Release中的NAS源码包不含密钥。

Android APK仍为测试签名，不保证不同构建间覆盖安装；先同步并保留离线数据，不直接卸载旧版。Windows解压完整ZIP后运行nas_todo.exe，保留DLL和data；desktop-widget.cmd继续启动独立毛玻璃组件。
