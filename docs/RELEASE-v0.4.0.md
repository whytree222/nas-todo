# v0.4.0 毛玻璃桌面组件测试版

Windows 小组件改为烟灰绿的圆角玻璃卡片，保留带底色的材质、清晰文字和圆形勾选图标。

## 更新和使用

1. 先关闭旧版主界面和小组件，下载 nas-todo-windows-v0.4.0-x64.zip，完整解压并保留 DLL 与 data 文件夹。
2. 双击 desktop-widget.cmd 单独启动组件，或从主界面右上角的“桌面小组件”打开。
3. 点击圆形勾选框完成任务，已完成条目保留删除线。显示今天和未安排日期的待办，滚轮查看更多。
4. 表面只保留待办和右上角“…”菜单；打开主界面、同步、置顶、贴边收起和关闭都在菜单中。
5. 拖动顶部移动，右下角调整大小。拖到屏幕边缘后，鼠标移开约 0.9 秒自动收成小标签，移上去展开。
6. 关闭主界面后组件仍可保存和同步；主界面已关闭时，再关闭组件会完全退出。

位置和选项沿用原设置。应用身份及本机数据目录保持一致，无需删除旧数据或重新部署 NAS。

## 玻璃效果

支持的 Windows 11 使用系统 Acrylic 材质，图标和文字独立保持清晰。系统关闭透明效果、省电、非激活状态或较旧 Windows 可能显示带底色的卡片；仍保留完整背景和清晰对比度。系统行为见 [Microsoft Acrylic 文档](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)。

本次保留日历、安卓桌面组件和 NAS 同步。Android APK 仍为测试签名，不能保证覆盖旧版；不要卸载含有未同步修改的旧版。应用内自动更新尚未实现。
