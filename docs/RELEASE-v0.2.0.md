私有待办 v0.2.0 测试版新增日历页面、安卓桌面小组件和 Windows 常驻待办小窗。

### 日历

打开“日历”页面，切换月份，点选日期查看当天所有待办。按现有截止日期归入对应天，没有日期的待办在“未安排”中。日期下方显示“未完成 / 全部”数量。勾选后保留该条目并划去文字，可再次勾选恢复；在选中日期新建待办会默认使用该日期。此页是应用内任务日历，没有接入系统日历账号。

### 安卓桌面小组件

安装后先打开应用一次，再长按手机桌面空白处 → 小组件 → “私有待办 · 今天”，拖到桌面。可调整大小；按高度显示当天前 1–8 条任务，其余可打开应用查看。

点勾选会唤起应用，将任务保存为选定的完成状态，离线也可保存，联网后沿用原同步流程上传。完成项显示删除线，冲突项显示“!”并需要在应用中处理。应用中编辑或同步后更新小组件；应用关闭时显示最近保存的本机副本，不会在后台独立拉取 NAS 数据。系统定期刷新日期，可能因系统省电策略延迟。小组件缓存仅包含显示任务的信息，不包含同步密钥和备注。

### Windows 桌面小窗

点击主界面右上角“桌面小窗”图标。拖动顶部标题移动位置，拖动边框调整尺寸，图钉按钮切换置顶；可以直接勾选、编辑和新增当天任务，并切换到“未安排”。展开按钮回到主界面，处理所有任务、日历、连接设置与冲突。同一应用实例切换界面，避免两个程序同时修改离线队列；重复启动会激活已有窗口。置顶与小窗模式目前不跨重启保存，没有开机自启。

### 下载与更新

- 安卓：下载 `nas-todo-android-v0.2.0-test.apk`，Android 7.0 及以上。
- Windows x64：下载 `nas-todo-windows-v0.2.0-x64.zip`，完整解压后运行 `nas_todo.exe`；更新时关闭旧程序并替换完整程序文件，保留用户应用数据目录。
- `INSTALL.md` 为本说明，`SHA256SUMS.txt` 为安装文件校验值。

安卓仍是云端调试签名测试包，没有固定长期签名。此版不能保证覆盖原 v0.1.0；不要直接卸载有未同步修改的旧版。先确认同步成功并备份 NAS；如发生签名不兼容，迁移前需妥善保留离线内容。固定签名及应用内下载更新还未实现。

NAS 服务与现有数据格式兼容，不需要重新部署 Compose。保持 ZeroTier 连接，客户端连接设置使用自己的 NAS 地址与原同步密钥；安装包没有内置密钥。云端自动测试与编译不替代手机桌面小组件、Windows 原生拖动置顶和真实 NAS 的实机验收。
