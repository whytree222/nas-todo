# v0.6.2 日历显示全部待办测试版

取消日期格只预览一至三条的限制。每一周按待办最多的一天自动增高，直接展开当天所有待办；完成后保留原位置并划线。

任务多时，整张日历可以上下移动：Windows 使用滚轮、拖右侧滚动条，或按住日历空白处拖动；安卓上下滑动。七列继续适配窗口宽度。日期格中的“详情”可打开当天全部待办的完整名称、备注及编辑入口。

未安排卡片继续固定显示，Windows 拖动卡片、安卓长按拖动到日期。修改先保存本机，联网后同步到 NAS。

Windows：关闭旧主界面和组件，下载 nas-todo-windows-v0.6.2-x64.zip，完整解压后运行 nas_todo.exe 或 desktop-widget.cmd，保留 DLL 和 data 文件夹；沿用原用户数据目录。

安卓：下载 nas-todo-android-v0.6.2-test.apk。本 APK 仍为测试签名，更新前先同步；不要直接卸载含有未同步待办的旧版。

NAS Compose、密钥和数据库无需修改。源码和安装包按使用者授权公开，NAS 密钥、数据库和待办内容未包含在发布文件中。
