# v0.5.0 主题颜色测试版

应用和桌面小组件新增黑、白、绿、蓝四种颜色。在应用的“设置 → 外观与主题”中选择，保存后立即显示；重启后保留选择。

## 选择颜色

1. “应用主题”控制安卓与 Windows 主界面。黑色使用深色界面，白色使用中性浅色界面，绿色和蓝色使用对应强调色。
2. “小组件主题”可选“跟随应用”，也可单独选择黑、白、绿、蓝。Windows 组件保留毛玻璃材质、勾选和贴边收起，安卓小组件也采用所选颜色。
3. 颜色设置保存在当前设备。手机和电脑可以采用不同颜色；无需修改 NAS 或同步密钥。

## 更新

Windows：先关闭旧版主界面和组件，下载 nas-todo-windows-v0.5.0-x64.zip，完整解压并保留 DLL 和 data 文件夹。双击 desktop-widget.cmd 启动组件，或运行 nas_todo.exe 打开主界面。沿用原来的待办、连接设置和窗口位置。

安卓：下载 nas-todo-android-v0.5.0-test.apk。本 APK 仍使用测试签名，不能保证覆盖旧版；不要卸载含有未同步待办的旧版。应用内自动更新尚未实现。

支持的 Windows 11 使用系统 Acrylic；非激活、省电、关闭透明效果或较旧系统可能显示带底色的备用卡片。颜色选择仍有效。
