# v0.6.1 日历显示修复测试版

应用版本：0.6.1+7。本次修复日历部分内容被遮住、无法移动的问题。

## 日历使用

- 日历按窗口宽度完整显示七列，按月份实际天数显示四至六周，无需横向移动寻找日期。
- 每天根据可用空间预览一至三条待办；完成后保留文字并划线，点击“+N 项”查看当天全部任务和完整名称。
- 高度不足时可上下滚动，右侧滚动条始终可见。Windows 可用鼠标滚轮、拖动滚动条，或拖住日历空白处上下移动；手机可上下滑动日历。
- 新建待办入口移到日历页顶部，避免悬浮按钮遮住日期。“未安排”区域继续固定在电脑日历旁、手机日历底部。
- 安排日期方式沿用上一版：Windows 拖动未安排卡片，安卓长按卡片后拖到日期；目标日期会高亮。修改先保存在本机，联网后同步到 NAS 与另一设备。

## 更新

Windows：关闭旧主界面和组件，下载 nas-todo-windows-v0.6.1-x64.zip 并完整解压，保留 DLL 和 data 文件夹。运行 nas_todo.exe 或 desktop-widget.cmd；沿用原用户数据目录。

安卓：下载 nas-todo-android-v0.6.1-test.apk。本 APK 仍使用测试签名，不能保证覆盖旧版本。更新前先同步待办，不要卸载含有未同步内容的旧版。

NAS Compose、同步密钥和数据库无需为这次更新修改。源码和安装包按使用者授权公开，NAS 密钥、数据库和待办内容不包含在发布文件中。
