# v0.6.0 日历待办与拖动安排测试版

日历日期格直接显示待办名称。点击任务前的圆形勾选图标或整条任务即可完成，完成后任务保留并划去文字。

## 日历使用

- 每天最多预览三条任务；点击“+N 项”查看当天全部待办和完整名称。
- “未安排”区域固定在电脑日历旁边、手机日历底部。Windows 拖动卡片，安卓长按卡片后拖到日期；目标日期会高亮。
- 手机可横向滑动查看其余日期。拖动时在日历的上、下、左、右边缘停留，可继续滚动到其他日期；也可先切换月份再拖动。
- 拖动只设置日期，保留任务 ID、名称、备注、清单、优先级和完成状态。修改先保存本机，联网后同步到 NAS 与另一设备；保存失败、取消拖动或目标发生同步冲突时保留原任务。
- 已同步到其他日期或已删除的任务不会被旧拖动覆盖。颜色设置和 Windows 毛玻璃小组件沿用 v0.5.0。

## 更新

Windows：关闭旧主界面和组件，下载 nas-todo-windows-v0.6.0-x64.zip 并完整解压，保留 DLL 和 data 文件夹。运行 nas_todo.exe 或 desktop-widget.cmd；沿用原用户数据目录。

安卓：下载 nas-todo-android-v0.6.0-test.apk。本 APK 仍使用测试签名，不能保证覆盖旧版本。更新前先同步待办，不要卸载含有未同步内容的旧版。

NAS Compose、同步密钥和数据库无需为这次更新修改。真实手机拖动手感、桌面显示、多显示器及 ZeroTier 双端同步仍需设备验收。
