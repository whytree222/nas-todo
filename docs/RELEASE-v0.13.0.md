# NAS Todo v0.13.0 · 应用内更新

- Android、Windows 在设置中检查新版本，查看说明、下载进度、取消及稍后提醒。
- 安全时每天自动检查一次；失败后至少一小时再自动尝试。编辑、同步或后台状态会暂停更新操作。
- 当前使用 NAS Todo 的 GitHub Release，Gitee 通道预留但未启用，不连接其他应用的仓库。
- 校验大小、SHA-256、版本与程序身份；安卓还要求与当前安装包签名一致，交由系统安装器确认。
- Windows 使用独立更新程序，主程序与桌面组件退出后替换程序文件；文件占用等失败会回滚，保留本机待办与配置。
- 不强制更新，不采集使用数据，不改变 NAS 数据或同步协议。

## 首次安装这个版本

旧版本没有更新模块，需要手动安装本版一次，以后可在“设置 → 应用更新”更新。

Android 从本版起采用长期固定发布签名。旧版使用临时 debug 签名，若系统提示签名不同，无法直接覆盖；不要未备份就卸载旧版。请先确认所有离线修改已同步到自己的 NAS，再按实际设备提示迁移。新旧签名不兼容时，应用不会绕过校验强行安装。

Windows 退出原主程序与桌面组件后，解压完整安装包运行 nas_todo.exe，保留 nas_todo_updater.exe、DLL 和 data 资源。使用可写的程序目录；后续更新会自动替换并重启。

已有 v0.11.0 成就服务的 NAS 无需重新部署。
