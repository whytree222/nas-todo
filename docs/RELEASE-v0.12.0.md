# NAS Todo v0.12.0

- 分类支持删除：点击分类旁的“分类操作 → 删除分类”，或打开分类后点击顶部删除按钮。确认后其中全部待办移到收件箱，日期、完成状态、备注、标签及子任务保留。
- 新增“周待办”：手机从左侧清单菜单进入，Windows 从左侧周视图图标进入。
- 先在待分配区添加本周想做的事，再点击“安排日期”选择周一到周日；电脑可直接拖动，手机可长按拖动。
- 已有分类中安排到本周的待办也显示在七天安排区，修改日期保留原分类。
- 无日期的周待办自动延续；已安排的按原日期保留，不会自动改期。完成的每日待办以划线显示。
- 安排到具体日期后，今天、日历、小组件和现有成就统计继续使用同一条待办。无日期的周待办不计入成就。

## 安装

Android 下载 APK 覆盖安装；Windows 退出主程序和组件后解压新包运行 nas_todo.exe，原数据保留。
已使用 v0.11.0 成就服务的 NAS 无需重新部署，本次继续使用现有接口、ZeroTier 地址和密钥。
