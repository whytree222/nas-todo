# v0.7.0 星星与年度成就测试版

新增“成就”页面：每周完成率 ≥80% 显示一颗星，全年十二个格子记录月份。月底每个有待办的周段都达标则绿，有未达标周段则红，无待办则灰；进行中月份暂为灰，点选月份查看详细比例。跨年自动显示下一年度，也可回看旧年。

周按本月内周一至周日分段，月初月末可为短周；按安排日期统计，有日期的未分类任务也参与完成率。月内星星实时预览，月底按 NAS 已收到的数据定格并保留历史。

本次必须同时升级 NAS 成就服务，参见 [NAS 升级说明](https://github.com/whytree222/nas-todo/blob/main/docs/UPGRADE-v0.7.0.md)。服务每分钟检查月底，结算与归档清理在同一事务中执行；自动清理该月有日期、有分类的全部待办，包括未完成的。无日期、收件箱、未分类保留。首次启用从当月开始。

月末请及时同步。离线修改与月底清理发生冲突时保留供选择，结算之后新到达的过期待办保留，历史结果不回改。历史成就与任务归档保存在 NAS，同步后客户端可离线查看成就。

Windows：关闭旧主界面和组件，完整解压 nas-todo-windows-v0.7.0-x64.zip，保留 DLL 和 data，运行 nas_todo.exe 或 desktop-widget.cmd。

安卓：下载 nas-todo-android-v0.7.0-test.apk。仍为测试签名，更新前先同步，不要卸载含有未同步待办的旧版。

公开服务升级包 nas-todo-server-v0.7.0.zip 不含真实密钥、数据库和待办。当前对话另提供沿用原部署的私有 Compose 配置，请勿公开。
