# v0.8.0 安卓滑动小组件测试版

新增五种桌面小组件：今日清单、全部待办、未来七天、简洁今日、卡片轮播。

- 今日清单显示当天已安排任务，全部待办包括无日期和完成项，未来七天显示今天起的七个自然日。
- 四种列表样式可以在桌面上下滑动查看全部任务，不再仅显示前几条；卡片轮播可上下滑动切换单条任务。
- 滑动和阅读标题不会打开主应用；右上角“↗”打开应用，明确点击勾选框会打开应用保存完成状态，冲突项打开应用处理。
- 沿用黑、白、绿、蓝主题以及已完成的删除线。小组件读取最近保存的本机副本，关闭主界面后仍可浏览；未打开应用时不保证后台 NAS 同步。
- 列表、简洁和卡片有不同的默认尺寸，可以长按小组件调整大小。简洁今日从2×2起，列表建议4×3或4×4，卡片建议4×3。

安装：下载 nas-todo-android-v0.8.0-test.apk，先打开应用一次，再长按桌面空白处 → 小组件 → 私有待办，选择样式并拖到桌面。旧“今天”小组件保留原身份并升级为可滑动清单；若桌面仍显示旧布局，可移除该桌面小组件再重新添加，不需要卸载应用。

安卓 APK 仍为测试签名，更新前先同步，勿卸载含有未同步待办的旧版。NAS 已升级v0.7.0者不需要为小组件再次修改 NAS。Windows 完整 ZIP 为 nas-todo-windows-v0.8.0-x64.zip，保留全部DLL与data目录。

实现采用 [Android 集合小组件](https://developer.android.com/develop/ui/views/appwidgets/collections)，滑动由桌面宿主的原生 ListView / StackView 处理。不同手机桌面的手势和尺寸仍需实机验收。
