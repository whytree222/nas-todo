# v0.3.0 透明桌面组件测试版

Windows 桌面组件可单独启动，主界面和组件可以同时显示，关闭主界面后组件继续使用。

## Windows 使用

1. 下载 nas-todo-windows-v0.3.0-x64.zip，解压完整目录，保留 DLL 和 data。
2. 双击 desktop-widget.cmd 直接启动组件；也可从 nas_todo.exe 主界面的“桌面小组件”按钮打开。
3. 首次使用通过组件的“主界面”进入设置，填写已有 NAS 地址和访问令牌。
4. 组件背景透明，桌面壁纸透出；文字、勾选框和小按钮保持可见。点击勾选框完成任务，完成项显示删除线。
5. 拖动左上角“私有待办 · 拖动”到屏幕任一边缘，会吸附并在鼠标移开约 0.9 秒后收成小标签。鼠标移到标签上自动展开；可关闭“贴边隐藏”。
6. 右下角可调整尺寸，滚轮查看更多任务。“钉”切换置顶，组件记住位置、大小及选项。
7. 关闭主界面后组件继续保存和同步；主界面关闭时再关闭组件，会完全退出。再次运行主程序可打开主界面。

更新前关闭旧版主界面及组件，再运行新目录，无需删除本机待办或 NAS 数据。应用内自动更新尚未实现。

组件与主界面共用一个后台进程和同一离线队列。它是独立桌面窗口，不是 Windows 系统 Widgets 面板扩展，也不会创建第二份待办数据库。它不随 Windows 登录自动启动，可自行给 desktop-widget.cmd 创建桌面快捷方式。

## Android 与日历

保留 v0.2.0 的安卓“今天”桌面组件、月历和每日待办。Android 勾选会打开应用保存。APK 仍使用测试签名，不能保证覆盖旧版；不要卸载包含未同步修改的旧版。

## 验证

构建流程执行客户端分析、离线与同步测试、原生编译，以及 Windows 原生组件检查（透明属性、独立窗口、勾选、四边收起和悬停展开）。实机壁纸效果、多显示器拖动和 NAS 双端同步仍需在使用设备验收。
