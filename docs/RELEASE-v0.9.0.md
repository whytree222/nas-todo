# v0.9.0 今日鼓励与小组件紧急程度测试版

完成今天最后一项已安排的待办后，会出现带笑脸星星和彩纸动画的鼓励卡片，例如「你真棒」「你离梦想又近了一步」。手机和 Windows 主应用都支持。

- 按本机当天日期统计全部清单中的今日待办；任务必须先保存成功。无待办的日子、打开应用、同步、删除或改期不会新触发。
- 每台设备每天最多鼓励一次。卡片适配应用深浅主题，支持系统减少动态效果；小屏幕和大字体可滚动查看卡片。
- 通过小组件勾选也可触发。Windows 主界面隐藏时，鼓励保留到当天重新打开主界面再显示。
- 安卓小组件每条任务显示紧急程度徽标：蓝色「普通」、琥珀色「较高」、红色「紧急」。五种小组件都支持，已完成项仍显示徽标及删除线。
- 待办的紧急程度在应用编辑页面设置。颜色以外也有文字，黑白绿蓝小组件主题都可识别。
- 沿用上一版的桌面滑动列表和卡片轮播；浏览标题与滑动不会打开应用，明确勾选仍打开应用保存。

下载 `nas-todo-android-v0.9.0-test.apk`，更新后打开应用一次以刷新桌面副本。若旧小组件布局未刷新，移除该桌面组件后重新添加；不要因此卸载应用。APK 仍为测试签名，更新前先完成同步并保留未同步数据。

Windows 下载并解压完整的 `nas-todo-windows-v0.9.0-x64.zip`，保留 DLL 与 data 目录。NAS 已使用 v0.7.0 成就服务者无需为本次功能重新部署。小组件读取本机最近保存的副本，未打开应用时不保证后台 NAS 同步。
